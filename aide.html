Aide & Guide d'utilisation

📘 À propos de l'application

Mercredi Pédago est une application web Android responsive, conçue pour fonctionner entièrement hors ligne. Elle permet aux enseignants et responsables pédagogiques de planifier efficacement les animations du mercredi, en tenant compte des contraintes réelles du calendrier scolaire : jours fériés, devoirs surveillés, animations de zone, etc.

Grâce à une interface intuitive et une logique métier robuste, l’utilisateur peut :

  • 📅 Définir la période scolaire et les dates à exclure
  • 🧮 Générer automatiquement les mercredis disponibles
  • 📝 Associer un thème pédagogique à chaque mercredi
  • 💾 Sauvegarder et consulter les données localement, sans connexion
  • 📤 Exporter les programmations pour archivage ou partage

Définissez les dates de début et de fin de l’année scolaire. Ajoutez les mercredis à exclure (fêtes, devoirs, animations de zone). Cliquez sur "Générer" pour obtenir les mercredis disponibles.

Sélectionnez un mercredi disponible et associez-lui un thème pédagogique. Les données sont enregistrées automatiquement dans l’appareil.

Consultez les thèmes enregistrés au format JSON. Vous pouvez les copier ou les effacer. Une version Excel est en cours de développement.

L’application fonctionne sans connexion. Toutes les données sont stockées localement. Pour réinitialiser, utilisez le bouton dédié dans la configuration.
